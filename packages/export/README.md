# @calepin/export

Turning a validated manuscript into a file. The composition model is kept
strictly separate from per-format rendering: options, table of contents and
numbering, title page and metadata, and exclusion of internal elements by
construction rather than by filtering.

Exports run asynchronously and are delivered through short-lived signed links.

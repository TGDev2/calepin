# @calepin/coherence

Two adjacent responsibilities the backlog keeps in separate epics but which
operate on the same material:

- **Narrative memory (E12, CAL-126 to CAL-134)** — extraction of facts after
  writing, conflict detection against the bible, character state, per-character
  knowledge, objects, injuries and movements, timeline updates, and recomputation
  after a version is restored.
- **Audit engine (E13, CAL-135 to CAL-145)** — pluggable checks in five families
  (factual continuity, psychology, structure, style, originality), the
  `QualityIssue` lifecycle, targeted correction and full-manuscript audit.

If the two ever need to ship independently, this is the package to split.
